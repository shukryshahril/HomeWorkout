# Contributing

Please open an issue to discuss substantial changes before starting work.

1. Fork the repository and clone your fork.
2. Create a branch from the default branch for one focused change.
3. Make your changes and run `npm ci` and `npm run lint` from the repository root. Build the app with `npm run build` when possible.
4. Review your diff for personal data, credentials, database files and unrelated changes. Do not commit them.
5. Push your branch to your fork and open a pull request against the original repository's default branch. Describe the change, how you tested it, and any user-visible effects.
6. Address review feedback with additional commits and keep the branch up to date with the default branch.

Do not report security vulnerabilities in public issues; contact the repository owner privately.
